# DOGMA 1.0.57 / API Platform V5

Optional “Correggi scatti” for both Seedance video workflows. Saves the original plus a separate `_FIX.mp4`; no extra API generation. Content-based motion analysis detects short holds, isolated jumps and recurring cadence at the source framerate. Local timeline repair preserves frame count, timestamps, dimensions and audio packets. Selective RIFE 4.26 inference uses the original resolution and 16-bit RGB intermediates; 10-bit sources stay 10-bit. Reliably tracked pans with repeated jumps also receive restrained camera translation correction in the same encoding pass, bounded to 0.4% of each dimension, with narrow reflected edge fill and no crop/zoom. Camera correction is skipped for clean clips, unreliable tracking, zoom, rotation or reversing camera paths. NVIDIA hardware encoding is preferred, with software encoding fallback. Shot boundaries, intentional holds and motion checks limit unnecessary changes. Unchanged clips are copied without re-encoding. Saving/repair runs outside the async API event loop; concurrent outputs reserve separate filenames. Stop cancels local processing; errors preserve the already generated original. Project/scene library records include both variants and the repair report.

Video preview play overlay follows the supplied design: white filled triangle, thin outline circle, 50% opacity. The Run button is unchanged.

RIFE weights download automatically once (approximately 23 MB) into ComfyUI/models/DOGMA/rife, only when a repair is needed. The pinned model archive and weights are SHA-256 verified; no downloaded Python is executed. RIFE architecture and weights are MIT licensed; see LICENSE_RIFE.txt. Previous node IDs and workflows remain compatible.
