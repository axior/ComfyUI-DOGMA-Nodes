DOGMA Nodes 1.0.47

- Fix frame content, not just timestamps: exact-timestamp NUT intermediates and nearest-frame matching replace millisecond Matroska / floor matching, which repeated and skipped every third frame at 24 fps.
- Restitch by decoding each original frame exactly once. Preserve its timestamp, time base and protected native colour samples; replace only the selected matte area. Export H264 losslessly, retaining source audio packets where MP4 supports their codec. Files are larger than the previous CRF16 export.
- Keep raw generated frames for new trials. Recover 1.0.46 trials from their saved generated latents using VAE decode only; do not rerun H3 or use a preview that already lost frames. Update the recovered preview pointer. Older trials without saved latents stop explicitly instead of falling back to the original.
- Separate H3 generation-mask grow/feather from the final compositing matte. Default final matte uses the uploaded mask with 0-pixel grow and 8-pixel inward feather, preserving black window bars and carriage geometry even when H3 needs a larger generation area. Original shared-mask behaviour remains an explicit option.
- Preview either the H3 generation area or the exact final compositing area. Carry final matte settings through ordinary and early trial selection, without altering the frozen source/prompt/seed/reference/generation mask. Preserve mode can change final matte settings without new H3 sampling.
- Add independent H3 processing resolution: native 768-short-edge / about 1 MP (1024x768 at 4:3), chosen-trial resolution, or original resolution explicitly marked experimental. The exported master always retains the source geometry and timing. Size references consistently with the processing canvas.
- Record processing/export sizes, final matte settings, lossless encoding and file fingerprints. Clearly label older finals that lack these export fixes.

Validation: production-path CPU edit regressions (including masked/unmasked edit, saved-trial promotion, Turbo/standard selection, raw-latent recovery and no-sampling preservation); frame-identity tests for all 97 frames, VFR and fractional rates; 10-bit YUV and grayscale sources with nonzero timestamp origins; expanded generation mask with protected frame geometry; real user-trial recovery and restitch of all 97 original frames, zero changed protected RGB pixels, exact protected YUV samples and unchanged audio packets. Both mask preview areas were exercised in an isolated browser with the real uploaded mask. No live installation or publication is performed by preparing this release.

Visual limits: the earlier diagnostic export still showed the expanded matte over the carriage. The new separate matte addresses that compositing defect; the final edge remains adjustable. A real 1024x768 Turbo 4-step source-based edit completed with the native mask present but still retained wall/grid artifacts. Native resolution is not a guaranteed cure for instruction adherence. Preserve mode retains the selected generation's appearance, including any flaws and low-resolution detail. H3 development/regeneration can change or fail the requested edit. No test result here is a claim of artistic approval of the wall replacement.
