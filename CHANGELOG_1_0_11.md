# DOGMA Nodes 1.0.11

Opt-in nodes for workflow V5; existing node IDs retain their prior behavior.

- Three independent lazy phase switches, three external Power LoRA loaders and a dynamic sampler catalogue that dispatches native, DOGMA and RES4LYF through the corresponding implementation. Additional LoRAs precede the existing per-phase DAY/NIGHT adapters.
- An image-only inventory proposes zero to eight categories. Independent presence verification excludes absent/uncertain categories before SAM. It is still a probabilistic model check, not a guarantee of detection correctness.
- Manual mode pauses on named original/mask/overlay cards. Stable semantic IDs select the rendering branches; empty selection is supported. The browser panel can reopen and reconnect after refresh. Invalid, duplicate and stale selection IDs are rejected; interruption cleans pending state. No additional frontend pack is required.
- Ownership is resolved after selection. Unselected categories do not claim pixels and do not run captions or diffusion. Initial mask detection/audit remains necessary to present choices. Disabled phases prune models, analysis, sampling and saves, including internal diagnostic roots.
- Recovered whole-object/spatial grouping from earlier V54.5/V56/V68 design. Groups fitting the native resolution cap remain whole. Oversized instances alone use bounded spatial windows; no crop is downscaled. Per-category limits and deferred-region reports remain explicit.
- Mask defaults: raw text detector masks (refine_iterations=0), threshold .4 exposed, bounded 32 detections/category, up to three noun queries/four recovery views. Remove ambiguous group/crowd/place-name queries. Text conditioning retained; no return to the failed 1.0.9 box-only decoder or restrictive shape filters.
- Two candidates per larger audit sheet instead of four compressed candidates. Explicit FAIL is rejected by default; malformed replies remain REVIEW, not silently treated as PASS. Micro-hole cleanup is optional and limited to enclosed holes <=4 analysis pixels within a 0.5% per-instance area budget. No silhouette dilation, largest-component pruning or filling architectural openings.
- Existing exact semantic blend masks, inward feathering and native VAE padding remain. Phase2 8 steps Euler/simple, phase3 4 steps Euler/simple, all Lying Sigma 0.00 over .2-.8. Phase1 Qwen ARRI/1970s Italy prompt, denoise1,4K,CV,optional reference retained; phase1 extra LoRAs OFF.

Validation: static schemas, links, defaults, all eight phase switch combinations, zero/three/eight category execution ancestry, DAY/NIGHT prompt/model propagation; CPU tests for selector dispatch, category presence, audit batching, mask holes, ownership, whole-object/native tile geometry, asynchronous selection and interruption. Model calls mocked. No real-scene GPU segmentation/render or end-to-end ComfyUI frontend run was performed; output mask quality remains to be tested on the supplied scene.

Historical review: 45 semantic workflow copies found among local archives, including V56.11/16/17, V58 and V68, plus node releases 1.0.5 through 1.0.10. The refinement-OR hypothesis already existed in 1.0.9; it is not a newly proven cause. That release also changed decoder and shape filters, so its failures cannot isolate a single factor. V5 retains a user-adjustable refinement control for comparison.
